# Oriun — imagens para redes sociais

Repositório público de imagens finais aprovadas para as publicações oficiais do Oriun.

As imagens do Facebook são guardadas em `marketing/social/facebook/AAAA/MM/AAAA-MM-DD-tema.png`.

A publicação utiliza URLs HTTPS ligados ao commit de cada imagem. Apenas imagens finais aprovadas são armazenadas aqui; fontes, prévias, credenciais e documentação interna ficam fora deste repositório.

Site oficial: https://www.oriun.co.mz
