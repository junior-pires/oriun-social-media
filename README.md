# Oriun — imagens para redes sociais

Repositório público de imagens finais aprovadas para as publicações oficiais do Oriun.

As imagens do Facebook são guardadas em `marketing/social/facebook/AAAA/MM/AAAA-MM-DD-tema.png`.

Os vídeos finais aprovados são guardados em `marketing/social/videos/AAAA/MM/AAAA-MM-DD-tema.mp4`, com as legendas em `AAAA-MM-DD-tema.pt.srt`.

A publicação utiliza URLs HTTPS ligados ao commit de cada imagem. Apenas imagens e vídeos finais aprovados são armazenados aqui; fontes, prévias, credenciais e documentação interna ficam fora deste repositório.

Site oficial: https://www.oriun.co.mz
